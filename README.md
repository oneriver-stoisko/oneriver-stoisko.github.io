# OR Stoisko

Aplikacja do rejestrowania sprzedaży ONE RIVER (na miejscu i z wysyłką InPost), działa także bez internetu.

Adres: https://oneriver-stoisko.github.io/

Dane zapisuje w arkuszu „One River – Finanse” przez to samo API (Google Apps Script) co aplikacja Finanse
(https://szczechu699.github.io/oneriver-finanse/). Stoisko ma osobny adres, bo Chrome na Androidzie
mylił dwie aplikacje zainstalowane z jednego adresu.
